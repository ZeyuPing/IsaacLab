HX5 Trajectory Stabilization
============================

This section records the design and implementation status for the
trajectory-conditioned residual dexterous manipulation task requested for the
HX5-D20 hand platform.

The goal of this documentation is to make it easy for another developer to read
through the current state of the project, understand the intended architecture,
and continue implementation without needing to reconstruct decisions from chat
history.
