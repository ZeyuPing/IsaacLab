TacAda Trajectory Stabilization
===============================

This standalone Sphinx site is the local documentation entrypoint for the
TacAda trajectory-stabilization project. It is intentionally isolated from the
upstream Isaac Lab docs tree so it can build on a Mac without a full IsaacLab
or Isaac Sim installation.

Use this site for day-to-day project reading and handoff context. It documents
the intended task shape, the current implementation status, and the code paths
that matter for continuation.
